# SiteTrack Pro walkthrough

1. **Sign in:** enter the existing username and password. The overview shows the current India date, active projects, today's headcount, pending material indents and open issues. The project selector filters the overview. Finance cards appear for authorised roles.
2. **Projects:** create a project with client, location, dates and status. Optionally add initial BOQ rows. Use Edit project to update details, or open its card for BOQ progress.
3. **Daily Work:** choose project/date and enter the work, location, quantity, category, subcontractor and responsible team. Delayed work is marked as carry forward. Date/project filters also control Excel and PDF exports.
4. **Progress:** link the entry to the correct BOQ item. Record the completed quantity and work status. The saved entry increases the BOQ completed quantity, up to its total. Export the filtered records.
5. **BOQ:** edit item descriptions, units, quantities and completed quantities inline. Authorised finance users can edit rates. Add variations using the Extra item option. Progress and remaining quantities calculate automatically.
6. **Materials:** maintain material names, units, categories and opening balances. Record inward and consumption transactions. Stock reconciles opening plus receipts minus consumption. Low stock is flagged.
7. **Indents:** engineering/quality creates a list of materials, sizes and categories with an approval note. Management/quality can hold individual items. Procurement prices each pending item and uploads each vendor's original quotation. After two quotations, MD compares prices and approves one or rejects all. Download the indent or approved PO/WO as Excel. Held items stay excluded.
8. **Labour:** choose the date, project, subcontractor and shift. Use Now for in/out time. Add categories with trade, skill, male/female headcount and permitted wage inputs. Edit same-day entries when attendance changes. Management can correct historical attendance. Finance users see updated trade and subcontractor costs.
9. **Issues:** raise a snag with priority, category, assignee and optional photo. Update status and resolution remarks. Unresolved issues feed the notification bell.
10. **Subcontractor ledger:** finance users record work orders, bills, advances, retention and deductions, and compare invoiced/paid balances. Export the current ledger.
11. **Vendor ledger:** finance users record purchases, advances, returns and debit/credit notes. Review vendor totals and invoice versus PO differences.
12. **Material orders:** create one master order, then add multiple delivery challans. Received, pending and percentage figures update after each delivery. Completed orders stop accepting further deliveries.
13. **Vendor directory:** MD, procurement and admin maintain vendors, search contact details and categories, call a mobile number, and open a visiting-card photo. Export the directory.
14. **QMS reports:** select project and date range, review consolidated work, progress, labour, issue and stock summaries, then export Excel/PDF. BOQ and stock balances represent cumulative/current values rather than work completed only in the selected date range.

The sidebar adapts to the account role. Financial values are protected by the staged database access changes, not solely by hidden UI controls. See RELEASE.md for the pending production migration and release gates.
